# 初回割引の受付枠

トップページ上部、トップページの初回予約欄、膝の痛みページの初回予約欄は、`data/first-visit-discount.json` を共通で読み込む。

ユーザー指定の受付上限は週5名、2026年10月26日（月）から11月1日（日）の残数は2名。これは割引の申込枠であり、当日の施術の空き枠ではない。期間内に連絡を受け付け、施術日時はLINEで相談後に確定する。

## 更新

- `weeklyCapacity`：週の割引受付上限。
- `weeks` のキー：日本時間の月曜日の日付。
- `remaining`：その週の実際の割引残数。現在は `weeks["2026-10-26"].remaining` が `2`。
- 受付状況が変わったら該当週の `remaining` を更新して公開する。3か所が同じ数字になる。
- 次の週は新しい月曜日をキーに、その時点での実際の残数を登録する。未登録の週は前週の数字を使わず、「残枠はLINEでご確認ください」と表示する。
- `0` の場合は「今週の割引受付は終了しました」。不正値、取得失敗時は残数を表示しない。

期間は日本時間の月曜〜日曜。期限日と週の選択は自動で切り替わる。人数を曜日や乱数で減らす処理や、LINEの予約を自動取得する処理はない。ページ読込時、タブに戻った時、日本時間の午前0時に情報を更新する。

## 構成

- `scripts/first-visit-week.js`：受付週の計算と表示、設定の読込。
- `styles/first-visit-week.css`：参考画像に合わせた期限・人数・赤い残数表示。狭い予約欄では縦に配置する。
- `tests/first-visit-week.test.mjs`：日付境界・週選択・残数の値域など13項目。
- 矢印はLucide Static 0.468.0のArrow Right。取得元 `https://cdn.jsdelivr.net/npm/lucide-static@0.468.0/icons/arrow-right.svg`。ライセンスは `image/icons/lucide-LICENSE.txt`。
