# コラム SEO・AIO コンテンツギャップ調査（2026年8月）

## 1. 結論

次に増やすべき内容は、膝やしびれの記事ではなく、次の2クラスターとする。

1. 足をかばう歩き方、杖、身体の傾きと、首・肩・腕の負担を一緒に確認する記事
2. 足腰の筋力、骨の健康、低栄養、サプリメントを食事の面から整理する記事

ただし「足腰が上半身痛の原因」「この栄養素で痛みが軽くなる」とは書かない。

足腰と上半身の症状が同時に見られる生活場面を取り上げ、別の病気や負担もあり得ることを伝える。栄養記事は食品と食事全体を中心にし、持病、服薬、食事制限がある人には医師や管理栄養士への相談を案内する。

## 3. 足りないもの

### 優先度A：検索実績を使った企画判断

リポジトリ内にはSearch Consoleの書き出しデータがない。現時点の提案は、記事構成と検索結果から確認したコンテンツギャップに基づく。

次回はSearch Consoleから直近3か月とその前の3か月を出力し、次を優先する。

- 表示回数が増えている
- 平均掲載順位が5～30位
- 表示回数に対してクリック率が低い
- 既存記事へ流入している関連語がある
- スマートフォンの表示回数が多い

Google Search Consoleで利用できる場合は、生成AIパフォーマンスレポートも確認する。ページ、端末、国、期間ごとの表示回数を記録する。

### 優先度A：重複記事の整理

次の組み合わせは検索意図が近い。新規記事を追加する前に、タイトル、導入、内部リンクの役割を分ける。

- 「朝起きると腰が痛い」2記事
- 坐骨神経痛3記事
- 「膝に水がたまる」2記事
- ベーカー嚢腫・膝裏の痛み2記事
- 既存の筋肉がつる記事と、夜間のこむら返り記事

同じ疑問に答えている場合は統合または旧記事からの誘導を検討する。病名の説明、生活場面、受診目安のように意図が異なる場合は、H1と導入で違いを明確にする。

### 優先度A：川上卓哉の経験が分かる本文

一般的な医学情報だけでは、他サイトと差がつきにくい。各記事に「当院で確認する生活場面」を100～250文字ほど入れる。

書いてよい内容は、実際に問診で聞くこと、姿勢・歩行・動作で見ること、説明するときに注意していることに限る。架空の症例や結果は作らない。

### 優先度B：画像検索と構造化データ向けの画像

現在の主画像は主に3:2で、`BlogPosting.image`には1枚だけ入っている。GoogleはArticle画像について、可能なら16:9、4:3、1:1の高解像度画像を複数用意するよう案内している。

今後は記事ごとに、文字を入れない代表画像から次を生成する。

- 1200×675px：16:9
- 1200×900px：4:3
- 1200×1200px：1:1

記事内の見出し入り画像は残してよいが、構造化データには文字なしの代表画像を優先する。画像は本文の近くに置き、内容を説明するaltとキャプションを付ける。

### 優先度B：栄養カテゴリー

現在は栄養記事が0本で、分類もない。最初の栄養記事を公開するときに「食事・栄養」カテゴリーを追加する。

整体院が栄養指導や診断を行うようには見せない。公的情報を分かりやすく整理し、持病や個別の制限については医師、薬剤師、管理栄養士へつなぐ役割とする。

### 優先度C：frontmatterの表記統一

生成後の画面ではカテゴリーが8種類に正規化されている。一方、原稿には `膝痛` と `膝の痛み`、`腰痛` と `腰の痛み` などの別表記が残る。

表示上の問題ではないが、今後の集計や原稿管理で迷わないよう、原稿側も正式名称にそろえる。

## 6. SEO・AIO向けの記事仕様

Googleの生成AI検索向けに特別な `llms.txt` や専用schemaを追加する必要はない。通常の検索と同じく、索引登録、クロール可能な本文、独自性、信頼性、内部リンク、読みやすさを優先する。

各記事は次の順にする。

1. H1の直下で、検索した疑問への答えを2～3文で示す
2. 「原因は一つとは限らない」「この記事で断定できないこと」を短く示す
3. 日常生活で確認する場面を説明する
4. 受診を優先する変化を説明する
5. 当院で確認できる範囲を事実の範囲で説明する
6. 関連する症状ページ1件とコラム2～3件へ本文内リンクを置く
7. FAQは本文で実際に回答した質問だけ3問前後にする
8. 公的機関、医学会、診療ガイドラインなどの出典を末尾に置く

AI検索向けという理由で短い段落を大量に並べたり、似た質問ごとに別記事を作ったりしない。読者が一度で疑問を整理できる範囲にまとめる。

## 7. 画像方針

### 共通スタイル

- 淡い生成り色の背景
- 水彩と色鉛筆を合わせたような医療イラスト
- 60～70代の日本人を自然に描く
- 服はセージグリーン、くすんだ青、紺を基本にする
- 痛みの表示は淡いオレンジを小さく使う
- 深緑の日本語見出し
- 不安をあおる表情、強い赤、過度な骨格透過を避ける
- 因果を示す矢印を使わない
- 運動を紹介するときは、正解を一つに決める図にしない

### 1記事の画像構成

1. hero：生活場面とテーマ
2. body-areas：確認する部位や動作
3. factors：一つに決めないための情報整理
4. self-check：症状を再現せずに記録できる内容

本文の内容が決まってから2～4を作る。先に画像を量産して、後から文章を画像に合わせない。
