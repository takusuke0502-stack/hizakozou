# 全記事の冒頭INDEXブロックの削除

実施日：2026年10月31日。ユーザーの「本文までが長くなる」という希望に沿って、記事自体ではなく、冒頭の「INDEX／この記事の内容／先に確認したいこと」を全79記事から削除した。

## 変更

- `scripts/build-blog.mjs` の `buildPostContent` から冒頭ブロックの出力を除去。専用の `buildArticleReadableOverview` と `ARTICLE_OVERVIEW_PRESETS` も削除し、次回の再生成で復活しないようにした。
- 元のMarkdown、記事タイトル、本文、写真、FAQ、本文中の受診案内、参考資料欄、目次と相談導線は維持。
- 既存の2件のテスト期待値を新しい表示へ変更。先行作業の参考資料の折りたたみ表示も保持。
- 単一ソース生成コマンドを実行し、全79記事を再生成。`blog/` 配下の本文を直接編集していない。

## 確認

- 作業開始時のスナップショットと79記事すべてを照合。対象ブロックの除去以外の本文変更がないことを空白を除いて確認。HTML以外の生成ファイルと元Markdownも照合し、空行だけの差分14件は開始時の状態に戻した。
- `npm run check:blog-links`：80ページ・3,394参照、成功。
- `npm test`：188件成功、100件スキップ、既知の2件失敗。失敗は腰痛・坐骨神経痛ページのFAQメニュー検査で、今回の変更前と同じ。
- 靴・サポーター・慢性痛の3記事を390・768・1440pxで確認。冒頭ブロックなし、横はみ出しなし、画像読込・見出しの表示を確認。代表画面を目視点検。
- スマートフォンのメニュー開閉、折りたたみ目次から本文への移動、相談リンクを確認。
- GitNexusはbuildArticleReadableOverviewの直接依存buildPostContent 1件をLOW、buildPostContentは上流0件と報告。ただし索引は古く、影響なしの証明とはせず、現行の呼び出し元・全出力の差分・テストで確認した。
