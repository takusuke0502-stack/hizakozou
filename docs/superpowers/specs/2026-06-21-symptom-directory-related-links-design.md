# 症状一覧・関連症状リンク再設計

## 目的

症状別ページ下部で同じ足腰リンクが繰り返される状態を解消し、既存の24症状ページを部位別に探せる導線へ再編する。

## 症状一覧ページ

`symptoms/index.html`を症状ページの総合案内所として扱う。

- 見出し: 「症状別ページ」
- 導入: 「気になる場所から症状を探す」
- PCは2列、767px以下は1列
- 大きなカードを大量に並べず、部位見出しと横長リンクで構成
- 次の6グループを表示
  - 腰・お尻・脚
  - 股関節
  - 膝
  - 足首・足裏
  - 首・肩・腕・手
  - 背骨・姿勢・顎
- 既存の24症状ページをすべて掲載
- `noindex,follow`の肩こり、五十肩、顎関節症もサイト内回遊用リンクとして掲載

## 個別症状ページ

各ページの`RELATED_SYMPTOMS_NAV`範囲を、そのページと関係が深い3〜4件へ絞る。

- 現在表示中のページは候補から除外
- 膝ページ同士、腰・神経ページ同士、首肩腕手ページ同士など、部位と動作の近さを優先
- 見出しは「この症状に関連するページ」
- 説明文は短くする
- カード群の下に「すべての症状を見る」リンクを設置
- 主要6ページにも関連症状リンクを表示し、関連記事スライダーとは別の役割を持たせる

## ナビゲーション

ヘッダーの主要6症状リンクは維持する。一覧ページへのリンク文言は「すべての症状を見る」に統一する。

## デザイン

- 既存の白・薄いクリーム・深緑を維持
- カテゴリーは開放的な区切り線中心で、カードの入れ子を避ける
- 症状リンクは44px以上のタップ領域
- 矢印は既存の丸いアクセントを維持
- 本文とリンク名のコントラストを確保
- 横スクロールを発生させない

## 生成と保守

`scripts/build-blog.mjs`を症状ナビゲーションの正とし、ブログ生成後も一覧・関連リンクが維持される構造にする。`symptoms/index.html`は専用生成関数で更新する。

## 検証

- 24ページが一覧に1回ずつ存在する
- 個別ページの関連リンクは3〜4件で、自分自身を含まない
- 全個別ページに「すべての症状を見る」がある
- 主要ページの関連記事スライダーを維持する
- 375px、768px、1440pxで表示確認
- `npm test`と`git diff --check`が成功する
