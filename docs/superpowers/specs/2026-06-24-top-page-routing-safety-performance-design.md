# TOPページ 回遊・安全性・技術改善 設計

## 目的

TOPページのヒーローを変更せず、症状別ページへの回遊、安全な受診案内、タブレット表示、読み込み負荷、計測と構造化データを改善する。

## 編集範囲

- `index.html`
- `styles/main.css`
- `scripts/main.js`
- `scripts/tracking.js`
- `scripts/tracking-config.js`
- TOPページ専用の軽量アイコンスクリプト
- `tests/lp.test.mjs`

## 変更しない範囲

- ヒーローのHTML、文言、画像、余白、CTA、表示順
- 電話番号、LINEリンク、予約フォームの送信先
- 料金、患者様の声、アクセス、FAQの表示内容
- 症状別ページ
- ブログ生成物

## 実装内容

### 1. 症状ページへの本文導線

ヒーローと既存の初回案内の後、かつ「こんなお悩みを抱えていませんか？」より前に、コンパクトな症状導線を追加する。

表示する主要6ページ:

1. 腰痛
2. 坐骨神経痛
3. 脊柱管狭窄症
4. 腰椎椎間板ヘルニア
5. 股関節痛
6. 膝痛

加えて「すべての症状を見る」から `symptoms/index.html` へ誘導する。カード説明は短くし、診断を断定しない。

### 2. 受診目安

症状導線の近くに、次のような場合は整体より医療機関への相談を優先する旨を掲載する。

- 急に力が入りにくくなった
- 排尿・排便に異常がある
- 事故や転倒後から強い痛みが続く
- 発熱や強い体調不良を伴う

不安をあおる赤色は使わず、既存の深緑と薄いクリーム色で表示する。詳しい受診目安は各症状ページへ委ねる。

### 3. 1024px表示

TOPページの共通ヘッダーを、症状別ページと同じく `1079px` 以下でモバイルヘッダーへ切り替える。1024pxで電話番号が右へはみ出さないことを確認する。

### 4. TOP専用アイコン軽量化

TOPページで使うLucideアイコンだけを含む軽量なローカルスクリプトを作成し、約388KBの全量バンドルから差し替える。

必要なアイコン:

- map-pin
- calendar-check-2
- user-check
- phone-call
- message-circle
- phone
- user-round
- check-circle-2
- leaf
- send
- x
- alert-circle
- loader-2

既存の `data-lucide` 属性と `window.lucide.createIcons()` の呼び出し契約を維持し、他ページには影響させない。

### 5. 画像読み込み

画面外にある `voice-result-banner.webp` を `loading="lazy"` に変更する。ヒーロー画像は引き続き `loading="eager"` と `fetchpriority="high"` を維持する。

### 6. GA4準備

GA4測定IDは未取得のため空欄を維持する。存在しないIDは作らない。

ID設定後に分析できるよう、次のイベントを追加する。

- `top_symptom_link_click`
- `top_all_symptoms_click`
- `top_medical_guidance_view`
- `top_contact_form_start`
- `top_contact_form_submit`

既存のLINE・電話・フォームのGoogle広告コンバージョン処理は変更しない。GA4 IDが空欄の間はエラーを出さず、イベント送信を行わない。

### 7. 構造化データ

- `MedicalClinic` を削除し、実態に合う `LocalBusiness` を中心にする
- 院長情報を `founder` の `Person` として追加する
- 住所、電話、営業時間、支払い方法など既存情報は維持する
- FAQの表示は維持し、`FAQPage` JSON-LDだけを削除する

### 8. レスポンシブ

- 767px以下は1列
- 768px以上は主要症状を2〜3列
- タップ領域は44px以上
- 375px、390px、768px、1024px、1440pxで横スクロールを発生させない
- モバイル固定CTAと新セクションを重ねない

## アクセシビリティ

- 症状導線はカード全体をリンクにする
- 見出し階層は新セクションを `h2`、症状名を `h3` とする
- 受診目安は色だけに依存しない
- フォーカス表示を明確にする
- 装飾アイコンは `aria-hidden="true"` とする

## 検証

- ヒーロー範囲のハッシュが変更前と一致する
- `npm test`
- `git diff --check`
- 主要6リンクと症状一覧リンクが実在する
- 375px、390px、768px、1024px、1440pxでブラウザ確認
- 1024pxを含め横スクロールなし
- 症状リンク、メニュー、施術フロー、問い合わせフォームの既存操作を確認
- コンソールエラーなし
- GA4 ID未設定でもJavaScriptエラーなし
