# 腰痛・脊柱管狭窄症・椎間板ヘルニアページ改修仕様書

## 対象ページ

- `symptoms/lower-back-pain.html`
- `symptoms/spinal-stenosis.html`
- `symptoms/lumbar-disc-herniation.html`

## 目的

柏市・柏駅周辺で腰痛、脊柱管狭窄症に伴う足腰の悩み、椎間板ヘルニアに伴う痛みやしびれに不安を感じている方へ、整体院ひざこぞうの確認内容、施術方針、運動療法とセルフケアの考え方を分かりやすく伝える。

## 改修方針

1. 坐骨神経痛ページ、変形性膝関節症ページと同じ思想で、読者が「自分の生活上の困りごとを相談できそう」と感じられる構成にする。
2. 施術実績は「施術歴15年、累計施術約2万件」に統一する。
3. 料金表示は初回1,980円のみとし、通常料金、回数券、残り人数、返金保証、強い限定訴求は表示しない。
4. 施術の流れはTOP由来の写真スライダーを使用し、各症状ページで重複した独自フローは追加しない。
5. 着替えの有無は記載しない。
6. 医療機関、薬、注射、手術を否定しない。整体院で診断できるような表現や結果保証は避ける。
7. 「治療」「治る」「完治」「根本解決」などの強い医療・保証表現は使用しない。

## 共通追加セクション

### ページ概要ファーストビュー

- 柏市・柏駅周辺の読者に向けて、症状名だけでなく生活上の不安へ呼びかける。
- 腰や患部だけでなく、姿勢、歩き方、関節の動き、身体を支える力、日常動作を確認する方針を伝える。
- 安心材料として、国家資格、施術歴15年、約2万件、完全予約制、柏駅西口徒歩8分を表示する。

### 当院が大切にしている5つのこと

1. 初回約90分かけて話と身体の状態を確認する
2. 痛む場所だけでなく、実際の動作を確認する
3. 動かしやすさ、支える力、実際の動作を順番に確認する
4. 整体と運動療法を組み合わせる
5. 自宅で取り組めるセルフケアを伝える

### 注意したいこと

- 痛みを我慢して強く揉む
- 症状が強くなる運動を無理に続ける
- インターネットの体操を状態確認なしで繰り返す
- 医師の指示なく薬を中止する
- 症状が急に変化しているのに放置する

### 自宅でできる対策

- 症状が増えない範囲で活動量を保つ
- 長時間同じ姿勢を避ける
- 強く伸ばしたり反動をつけたりしない
- 医師から運動制限を受けている場合は指示を優先する
- 自分に合ったセルフケアを専門家に確認する

### 院長メッセージ

川上卓哉本人が語りかける形で、痛みやしびれは本人にしか分からないつらさがあること、年齢や診断名だけで諦めてほしくないこと、一回で変化を保証しないこと、できることとできないことを誠実に伝えることを明記する。
