# 変形性膝関節症ページ改修仕様書

## 対象ページ

- `symptoms/knee-osteoarthritis.html`

## 目的

柏市・柏駅周辺で変形性膝関節症、歩き始めや階段での膝痛に悩む方に向けて、整体院ひざこぞうの考え方、確認内容、施術方針、相談前の注意点を分かりやすく伝える。

## 改修方針

1. 既存のSEOタイトル、メタディスクリプション、ヒーロー画像、悩みチェック、医療機関への案内は基本的に活かす。
2. 坐骨神経痛ページと同じ考え方で、以下の内容を追加する。
   - ページ概要ファーストビュー
   - 当院が大切にしている5つのこと
   - 膝痛・変形性膝関節症のときに注意したいこと
   - 自宅でできる対策
   - 院長からのメッセージ
3. 施術実績は「施術歴15年、累計施術約2万件」に統一する。
4. 料金は初回1,980円のみを表示し、通常料金、回数券、残り人数、返金保証、強い限定訴求は表示しない。
5. 施術の流れはTOP由来の写真スライダーを使用し、ページ独自の重複した流れセクションは削除する。
6. 着替えの有無は記載しない。
7. 医療機関、薬、注射、手術を否定しない。整体院で診断できるような表現や結果保証は避ける。
8. 「治療」「治る」「完治」「根本解決」などの強い医療・保証表現は使用しない。

## 追加セクション

### ページ概要ファーストビュー

- 柏市・柏駅周辺で変形性膝関節症と言われた方へ呼びかける。
- 膝だけでなく、立ち上がり、歩き方、階段、股関節、足首、身体を支える力を確認する方針を伝える。
- 安心材料として、国家資格、施術歴15年、約2万件、完全予約制、柏駅西口徒歩8分を表示する。

### 当院が大切にしている5つのこと

1. 話と身体の状態を丁寧に確認
2. 膝だけでなく実際の動作を確認
3. 動かしやすさ、支える力、実際の動作を順番に確認
4. 整体と運動療法を組み合わせる
5. 自宅で取り組めるセルフケアを伝える

### 注意したいこと

- 痛みを我慢して強く揉まない
- 症状が強くなる運動を無理に続けない
- ネットの体操を状態確認なしで繰り返さない
- 医師の指示なく薬や通院方針を変えない
- 急な腫れ、熱感、外傷後の痛みなどは医療機関へ相談する

### 自宅でできる対策

- 長時間同じ姿勢を避ける
- 症状が増えない範囲で歩く
- 膝だけを無理に曲げ伸ばししない
- 医師からの運動制限を優先する
- 自分に合うセルフケアを確認する
