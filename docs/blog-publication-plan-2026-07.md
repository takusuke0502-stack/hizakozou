# コラム公開計画（2026年7月〜8月）

## 方針

- 火・木・土の週3本を基本にする。
- 同じ部位や似た検索意図の記事を連続させない。
- 公開前に川上卓哉が本文・画像・医学情報を確認する。
- 公開日は `draft: true` を `draft: false` に変更し、記事生成後にプッシュする。
- 記事数を保つためだけの追加公開は行わない。

Googleは更新回数の多さではなく、人の役に立つ信頼できる内容を優先すると案内している。公開頻度はSEO施策そのものではなく、確認作業を無理なく続けるための運用ルールとして扱う。

## 1本を公開する手順

1. 対象の `content/source/*.md` を開く。
2. 川上卓哉が本文と画像を最終確認する。
3. `draft: true` を `draft: false` に変更する。
4. `date` と `reviewedDate` を実際の公開日・確認日に合わせる。
5. `npm run generate:blog:source -- --source content/source/対象ファイル.md` を実行する。
6. `npm test` と `npm run check:blog-links` を実行する。
7. 生成差分を確認してコミット・プッシュする。

## 公開後に確認すること

- Search ConsoleでURL検査を行い、サイトマップに含まれていることを確認する。
- 7日後と28日後に表示回数、クリック数、平均掲載順位、検索語句を記録する。
- 内部リンクのクリックと記事の読了率をGA4で確認する。
- 表示回数があるのにクリックされない記事は、タイトルとメタディスクリプションを見直す。
- 読了率が低い記事は、冒頭文、見出し、画像位置を見直す。
